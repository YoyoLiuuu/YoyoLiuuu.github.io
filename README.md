# yoyoliuuu.github.io

Personal academic website for **Yoyo (Yimeng) Liu** — CS + Chemistry researcher at the University of Toronto.

**Live at:** [yoyoliuuu.github.io](https://yoyoliuuu.github.io/)

The site covers my research (AI + chemistry/biology), publications, projects, work experience, and an interactive map of everywhere I've lived and worked. Built with Jekyll using the Academic Pages template.

## Running locally

```bash
bundle install
bundle exec jekyll serve
```

Then visit `localhost:4000`.
